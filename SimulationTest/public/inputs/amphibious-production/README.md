# Owned amphibious production fixtures

Generated by SimulationTest/tools/amphibious_fixture.py. Builder, helicopter and T1 factory assets reuse existing owned helicopter-production fixtures. The five jet sprites and T2 factory body are newly drawn integer-coordinate geometric art, using the same north-facing logical layouts as the qualified native resource bindings. No original game images, audio, bytecode or derived pixels are included. Native behavior values are independently implemented from private qualified evidence; the original core is not a runtime dependency.

The normal command-center start reuses owned command-center art from hover-production and owned ground-target, underwater-target and shoreline data from naval-production. INI, JSON and Hjson declare the same finite paid T1 → T2 → amphibious-jet chain. Core short scenarios cover physical state changes; platform scenarios execute the full normal production chain and record every action, payment, income tick and launch. These are self-behavior fixtures, not original-game execution evidence.
