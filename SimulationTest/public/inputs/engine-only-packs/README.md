# 独立开局示例

`field-base` 与 `field-extension` 是两个可独立放置的自有内容目录。启动和启用方法见[仅引擎安装](../../../../Engine/pc/README.md#仅引擎安装)。

只用基础包，开局资金为 3500。选中工人，放置工厂，花 700 施工。工厂完成后花 350 生产坦克。选中出厂坦克，右键下达对敌方坦克的攻击指令。双方坦克的护盾上限为 60，实际命中先消耗护盾。

`field-extension` 显式依赖基础包。它将 `field_tank` 替换为护盾上限 95 的同名单位，并添加护盾上限 120 的 `field_escort`。扩展同时替换工厂的生产清单，玩家可用同一个工厂付费生产护卫车。启用两包后沿用基础包的开局。内容管理页可查看工厂、坦克和护卫车的实际来源。

## 开局声明

可在基础包 `pack.json` 或 `pack.hjson` 添加 `opening`。它包含包内 `map` 路径、两个玩家的整数资金 `credits` 和 `opponentCredits`，以及 `units`。每个出生项给出唯一 `id`、`owner`、单位类型 `type`、世界坐标 `x` 和 `y`、角度 `heading`。至少有一个本地玩家 `p1` 的单位。地图、外部图集声明和图集图片均须位于同一包根目录中。每个启用组合可包含一个开局。

地图和单位图来自现有公开自有样本。地图图集随基础包的地图加载，独立资源选择仍处理单位和界面使用的视觉素材。
