# Gunboat content fixture

The existing content-pack reader loads `pack.json`. Select the sea factory and queue Gunboat from its standard action list. The authored gunboat has a 24-by-13 movement footprint. The passage between the two basins is 20 world units wide.

The authored content ID `gunboat` corresponds to the original unit reference `gunBoat`. The pack uses the existing JSON content format. Gunboat and wreck sprites and channel geometry are original to this fixture. The sea factory sprites and terrain tiles come from the repository-owned `../naval-production/json/` fixture.
