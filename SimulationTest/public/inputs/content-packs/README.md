# Local declarative tank packages

Three self-owned examples for the Content pack menu. Enter an amber-scouts directory, check it, choose amber_scout or amber_guard and enable it for the next match. Each uses a cross-format template and existing public placeholder PNGs. The selected scout has 250 HP, guard 320 HP; both retain existing ordinary tank movement and 25 direct damage. No original game assets or executable code.

Use an existing sandbox input directory for the controlled map. These packages contain units, not maps. Explicit cross-package dependencies/replacements are a separate capability.
