# Owned resource sound inputs

The source tones are generated from a sine at 523.25 Hz (bundled base) and880 Hz (user), with a sin-squared envelope,22050 Hz mono PCM16,3528 frames. No sampled game audio or melody. The script in the008 private evidence records generator/encoder identities; these files are owned public test inputs.

The Ogg is encoded from the owned user WAV with FFmpeg/libvorbis. Runtime users do not require FFmpeg; the PC application uses its existing libGDX dependency. Pack metadata requires resource capability2. Both packs supply only their own existing owned image icon and the tank-fire sound event, not unit images or gameplay. Hjson examples use valid JSON as a Hjson subset. Actual native output/listening evidence is separate from these files.

`weighted-sandbox/resources` uses the same owned tones and icon, with resource capability3 and sounds schema2. The lower JSON pack declares weights2:1 and a separate retained event. The replace JSON pack replaces only tank-fire with3:1. The append Hjson pack explicitly prepends its weight3 candidate to the lower2:1 table. The public short scenarios check exact final tables and legal actual choices; finite runs need not visit every candidate or reproduce exact weight proportions. The Runner uses the existing device-free sink, not a sound device.

Sounds schema2 keeps the `sounds` file table. An event is `{"candidates":[{"sound":"owned:sounds/shot","weight":2}],"append":true}`. Omitted weight is1; omitted append is false. Weight must be a positive decimal32-bit integer token, never a fraction, exponent, string, boolean or null. Empty candidate arrays, duplicate URI entries within one declaration, unknown fields and unresolved references are rejected. The pack metadata schema remains1, and settings schema is independent. Sounds schema1 single-`sound` events remain supported at resource capability2.

Priority is the existing one pack order: absent events survive; default replacement affects only the declared event; explicit append puts this layer before the lower table. Higher replacement cuts lower contributions, while every enabled declaration is still validated. Duplicate URIs across appended layers retain both weights. Candidate declaration providers and final sound-file providers can differ. Local presentation selects once per new authorized request, then applies actual-object deduplication within the outer frame; it does not redraw a skipped object or affect simulation random state.
