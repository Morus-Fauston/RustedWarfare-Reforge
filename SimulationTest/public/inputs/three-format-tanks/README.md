# 三格式公共坦克输入

INI、JSON、Hjson各目录是可由现有受控沙盒直接消费的独立输入；每目录恰有一个tank作者文件。地图、标记和图片逐字节复用本仓库production-combat/combat公共自有合成材料，没有原版资源。JSON/Hjson按rw-reforge.unit.v2静态声明同一坦克；Hjson仅在同义JSON之外使用正式注释和无引号版本字符串。

对应三条短测复用production-combat-short的固定动作和完整规则，改动场景/合同ID及该坦克的输入路径/哈希，不从新轨迹生成预期。它们证明本项目内容同义及既有生产/战斗，不证明原版、真实PC或性能。
