# Owned heavy-mech inputs

Three authored finite declarations and independent rectangle PNGs. Ordinary LAND development variant of mechHeavyMissile; shield and OVER_CLIFF remain outside this stage. No original game code, pixels or runtime dependency. The first package is a content boundary fixture, not a completed production scene.

Each `production-package` contains the owned builder, two-legged mech, finite T1 and T2 mech factories, four-legged LAND development variant and unchanged helicopter enemy. Choosing builder enables the controlled 600 by 400 production scene: 16000 credits, no factory or heavy initially, normal builder construction of T1 for 1000, upgrade for 4000, then heavy production for 8500. Factory upgrades and ordinary products use one FIFO. The three `platform/scenarios/heavy-mech-*-production-chain.json` plans exercise this actual chain and ground/air combat through the formal Session runner; HeavyMechProductionSessionTest checks their complete diagnostic archives. The short core/Session plans separately cover declared four-leg motion and real small-laser fire. Public headless evidence does not prove native PC input/rendering or original-game compatibility. Images are owned stubs, including the separate T2 body and named small turret.
