# 自有海军输入

INI、JSON、Hjson三份等义有限内容包包含岸边建造者、海军工厂T1/T2、原参数重型战舰、坦克/直升机敌靶和固定深度水下靶。声明与矩形PNG均为自有材料，不包含原版代码、像素或运行时依赖。固定水下靶只供依赖和验证使用，不出现在玩家可选列表，不代表完整潜艇机制。

完整包中的六个可选单位使用同一受控岸线场景：12000开局，己方只有建造者，在(450,150)实际建T1扣1000，普通升级T2扣2000，再生产重型战舰扣6000。工厂实体身份不变，升级和产品使用既有单一FIFO。地图左半干地、右半水面，另保留独立干岛及两种桥属性样本。

`naval-ground.png`为从空白像素生成的自有岸线图集，分别显示干地、水面、干桥和水桥。其相同字节随基础素材清单发布到经过校验的固定代际，有限`naval-ground-40`布局使用该绑定，显式同名地形资源可覆盖；旧原版包的五份陆地图集不替代这张水面图。启用原版单位和声音时，岸线背景仍是这张自有图，不代表原版地图画面。

`scenarios/naval-production-*-chain.json`与对应合同通过正式Core Runner执行8200步，固定升级4099、出生6699，完成正常建厂、升级、生产、离厂、移动、停止和地面/空中/水下交战。固定工作边界来自运行前独立binary32逐次求和；两种主炮使用地面快照，导弹/鱼雷使用单位目标，不能把主炮的空目标ID当丢失目标。Core旧combat加载器要求替换键，故其地面靶引用既有自有`three-format-tanks`旧声明；声明内容包禁止该键。两者玩法等义，字节身份分别保留。

`platform/scenarios/naval-*-production-chain.json`通过正式PlatformSessionRunner执行真实Session意图，保留随机nonce和完整诊断，不能与固定nonce的Core原始身份强行合并。NavalProductionArchiveTest完整消费三格式Core归档并逐行比较全部玩法值；NavalProductionSessionTest采集三格式正常链。公开无头测试不证明PC输入、GPU绘制、实际声音输出、原版兼容或最终人工接收。
