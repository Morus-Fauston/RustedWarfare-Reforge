# Owned Nautilus mobile-production input

`python -B SimulationTest/tools/nautilus_fixture.py` rebuilds the three equivalent content packages. Body/dead PNGs are geometric artwork generated by the project's own `aa_beam_fixture.png`; no original game pixels or runtime libraries are copied. Other content/art comes from the existing owned hover, naval-production and repairbay command-center fixtures.

`package` isolates the submerged mobile producer and its required hover-tank product. `production-package` adds the normal command-center → paid worker → paid sea factory → T2 upgrade → paid Nautilus chain. Only the required real hoverTank production item is included. Surface/land forms, weapons, scout payloads and anti-nuclear behavior belong to later tickets; this is not the complete representative.

Public self-behavior cases use independent DEC-qualified coefficients. They do not establish original compatibility, PC input, Android/device, network, performance or security acceptance. Original resource packs and private comparison evidence remain outside the public repository.
