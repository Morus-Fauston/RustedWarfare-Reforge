# 多单位寻路与迷雾演示

Windows 演示地图：64×40 格，50 个自有侦察坦克，使用独立核心真实执行移动和玩家知识寻路。地图、配置和贴图均为本项目自制。

## 启动

已在本机构建时，双击同目录 `run-demo.cmd`。需要 Java 17 或更新版本；脚本优先使用 `JAVA_HOME`，未设置时尝试本机 Microsoft JDK 25，再使用 PATH 中的 Java。

首次克隆先在 `Engine/` 运行 `gradlew.bat :pc:installDist`。构建需配置 JDK 25。启动脚本使用 `pc/build/install/pc/` 中的本机发行物，不需要原版游戏或内部一期样本。开发者运行完整核心/客户端回归时仍须准备内部一期测试输入，不能把它作为公开克隆的演示启动前置。

## 三分钟演示

1. 初始默认选中 50 个单位。亮色为当前可见地形；黑色为尚未探索。
2. 点击 **Advance**，整队前往右侧橙色目标。先规划穿过未知区域的路线，探索发现山水障碍后，路径会改走通道。底部 **replans** 来自核心实际重规划诊断。
3. 观察部队离开后的暗色地形记忆。未探索区域仍保持黑色。
4. 点击 **Stop**，单位取消目标、减速停止。**Pause / Resume** 暂停或恢复整个模拟。
5. 左键点一个单位可单选，右键点地图下达目的地；**Select all 50** 恢复整队选择。**Paths** 切换知识路径显示。
6. 点击 **Restart** 清除本局探索与命令，重新出现初始 50 单位。

## 演示规则和边界

视野为半径 120 世界单位（6 格）的圆，障碍不遮挡，探索地形永久保留。它是本次获批的演示规则，不是原版兼容结论。所有单位属于同一个本地玩家；不展示跨玩家共享视野。

单位共用目的地，当前没有动态单位碰撞、编队或群体避让，因此可能重叠。到达使用现有目标半径，停止会先减速。演示不证明 Android、硬核遗忘、原版对拍、正式性能阈值或二期整体验收完成。

运行诊断默认保存在 `pc/build/demo-runs/`，包含运行 JAR 的 SHA-256、指令、每秒观察及重规划/探索计数；它不是正式原版轨迹格式或性能报告。原一期沙盒默认入口保持不变。
